# Imágenes Requeridas para Proceso Administrativo

## Imágenes Necesarias

Para que las imágenes se muestren correctamente en la Sala 3 (Proceso Administrativo), necesitas subir las siguientes imágenes a la carpeta `IMAGENES`:

### 1. Planeación
**Nombre del archivo:** `PLANEACION.jpg` (o `.png`, `.webp`)
**Ubicación:** `IMAGENES/PLANEACION.jpg`
**Uso:** Se muestra en la tarjeta de "Planeación"

### 2. Organización
**Nombre del archivo:** `ORGANIZACION.jpg` (o `.png`, `.webp`)
**Ubicación:** `IMAGENES/ORGANIZACION.jpg`
**Uso:** Se muestra en la tarjeta de "Organización"

### 3. Dirección
**Nombre del archivo:** `DIRECCION.jpg` (o `.png`, `.webp`)
**Ubicación:** `IMAGENES/DIRECCION.jpg`
**Uso:** Se muestra en la tarjeta de "Dirección"

### 4. Control
**Nombre del archivo:** `CONTROL.jpg` (o `.png`, `.webp`)
**Ubicación:** `IMAGENES/CONTROL.jpg`
**Uso:** Se muestra en la tarjeta de "Control"

## Notas

- Los nombres deben estar en MAYÚSCULAS exactamente como se muestra arriba
- Puedes usar extensiones .jpg, .jpeg, .png o .webp
- Si la imagen no existe, simplemente no se mostrará (no causará errores)
- Tamaño recomendado: 200x200px o similar para que se vea bien en las tarjetas
- Las imágenes se mostrarán automáticamente una vez que las subas con estos nombres
